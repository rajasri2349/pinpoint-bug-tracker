\# 📍 PinPoint — Visual Bug Tracking Platform



PinPoint is a full-stack bug tracking tool that lets you upload a webpage screenshot, click directly on the bug location to pin it, and manage bug status through a live dashboard — instead of writing vague text descriptions like "the button on the top right is broken."



\## ✨ Features



\- 🖼️ Upload any screenshot and visually pin bugs with a single click

\- 📝 Attach title, description, and assignee to each bug

\- 📊 Live dashboard with bug counts (Open / In Progress / Fixed)

\- 🔍 Filter bugs by status

\- ✅ Update bug status or delete bugs in real time

\- 🗄️ Persistent storage with PostgreSQL — nothing is lost on refresh



\## 🛠️ Tech Stack



| Layer | Technology |

|---|---|

| Backend | Java, Spring Boot, Spring Data JPA |

| Database | PostgreSQL |

| Frontend | HTML, CSS, JavaScript (Canvas API) |

| Build Tool | Maven |
